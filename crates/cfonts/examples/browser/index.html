cfonts

Sexy ANSI fonts for the console█

A few ASCII fonts with colors, gradients and backgrounds, rendered by one Rust core for your terminal, node, the browser, the browser console and any Rust apps. 

$ cfonts "cfonts" -f block -c red-blue

Install

  • macos$ brew install cfonts
  • arch$ yay -S cfonts
  • fedora$ sudo dnf install cfonts
  • nixos$ nix-env -iA nixos.cfonts
  • macports$ sudo port install cfonts
  • rust$ cargo install cfonts
  • node$ npm install cfonts
