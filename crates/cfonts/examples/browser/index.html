cfonts

Sexy ANSI fonts for the console█

A few ASCII fonts with colors, gradients and backgrounds, rendered by one Rust core for your terminal, node, the browser, the browser console and any Rust apps. 

$ cfonts "cfonts" -f block -c red-blue

Install

  • macos$ brew install cfonts
  • arch$ yay -S cfonts
  • fedora$ sudo dnf install cfonts
  • nixos$ nix-env -iA nixos.cfonts
  • macports$ sudo port install cfonts
  • rust$ cargo install cfonts
  • node$ npm install cfonts

Browser

Pick a font, colors and a background, the page renders the block with the same API node uses. The canvas is an eighty column terminal, so long text wraps the way it would there. 

$

eighty columns

Devtools

The same call logs a styled banner into the devtools console, open it and pick. Every pick prints a banner, a typed text prints on enter. 

$

prints to the devtools console
